### Post-hoc disagreement adjudication

Case `rw-089` was the single new precision-eligible false positive introduced by framework-neutral model/tool-loop discovery. A pinned-source re-review found an explicit `DeepSeekMCPAgent` with all four required signals:

1. MCP tool catalogue acquisition;
2. tool catalogue exposure to the model;
3. model-selected `tool_calls`;
4. concrete MCP dispatch.

The original locked automated source reference contains zero agent roots for this case. Per the preregistered disagreement protocol, the locked truth was not overwritten. The correction is recorded separately at:

`research/real-world-agent-security-2026/adjudications/rw-089-agent-root.json`

Applying only that documented correction changes agent precision from:

Both values must remain visible. The post-hoc metric does not replace the preregistered result.

## What v0.9 actually fixed

### LangGraph

LangGraph was the largest baseline recall defect. The v0.9 semantic adapter now models graph roots and workflow nodes separately, classifies node roles, exposes standalone LangChain tools structurally, preserves control-flow topology, and avoids treating every deterministic graph node as an agent.

Final LangGraph recall:

- agent/workflow: **0.9613**;
- tools: **0.9660**.

### Framework-neutral agents

The model/tool-loop adapter recognizes unsupported-framework and custom agents only when source proves model invocation, model-visible tools, model-selected execution, and concrete dispatch.

MCP/custom agent recall is now **0.6250**. No discovered generic root receives effective authority merely because a tool or MCP server exists in the same module.

### MCP

Unbound MCP entities are now topology-visible without fabricated `INVOKES` edges. Discovery covers programmatic/config-backed servers, custom source-proven MCP wrappers, OpenAI Agents MCP definitions, and Pydantic AI MCP constructs.

Explicit MCP-server recall is now **19/22 = 0.8636**.

### Traversal

Unreadable paths, broken symlinks and inaccessible directories no longer abort repository scans. The final execution fix also prevents large irrelevant C/RTL/vendor payload from exhausting the 10,000 relevant-analysis-candidate limit while retaining a separate 100,000-entry traversal ceiling.

The final cohort executes **180/180**.

### Effective authority

Effective-authority precision remains **0.2778** and recall **0.6260**.

This is expected. v0.9 intentionally did not redesign authority binding. The low precision result remains the primary motivation for v0.10.
